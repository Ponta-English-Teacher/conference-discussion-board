# Conference Discussion Board

Purpose:
A bilingual conference discussion platform using sticky-note style questions.

Participant Information:
- Name / 氏名
- Affiliation / 所属

Core Features:
- Submit Question / 質問を投稿する
- Vote / 投票する
- Build on this Question / この質問を発展させる
- Shared Discussion Board
- Category Clustering
- Category Vote Counts
- Moderator View / 司会者画面

Main Objects:
- Session
- Participant
- Question
- Category
- Vote
- BuildOnComment
